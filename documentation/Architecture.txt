### **2. Component-by-Component Specifications**

#### **A. Frontend Stack (Member 5 & Member 6)**
* **Framework:** Next.js 14 (App Router) + TypeScript + Tailwind CSS.
* **3D Visualization:** `Three.js` + `@react-three/fiber` / `@react-three/drei`.
* **Key Components:**
  1. **Upload & Metadata Panel:** Displays Ground Sampling Distance (GSD), image resolution, and Coordinate Reference System (CRS/UTM Zone) upon file load.
  2. **Split View Comparison Canvas:** Side-by-side sync of raw optical RGB image, AI relative disparity map, and final calibrated Digital Surface Model (DSM).
  3. **Interactive 3D Terrain View:** Renders an orthorectified texture draped over an elevation-displaced plane geometry. Includes cubic Hermite spline camera interpolation for smooth automated flythroughs.
  4. **Elevation Cross-Section Tool:** Click two points on the 2D canvas to draw a line; renders a dynamic line chart (using `Chart.js` / `Recharts`) showing the terrain height profile in physical metres.

#### **B. Backend & REST API Layer (Member 4)**
* **Framework:** FastAPI (Uvicorn ASGI server).
* **Core API Endpoints:**
  * `POST /api/v1/upload`: Validates file format (GeoTIFF vs PNG/JPG). Extracts spatial bounding box, CRS code (EPSG), and resolution.
  * `POST /api/v1/infer`: Runs the PyTorch model to produce a relative disparity matrix (`.npy` file stored in scratch storage).
  * `POST /api/v1/calibrate`: Executes Cloth Simulation Filtering (CSF) and RANSAC scale-shift fitting against reference DEMs.
  * `GET /api/v1/export/geotiff`: Generates and streams a downloadable, fully georeferenced metric DSM GeoTIFF.

#### **C. Geospatial Ingestion & Tile Engine (Member 3)**
* **Core Libraries:** `rasterio`, `pyproj`, `GDAL`, `NumPy`.
* **Functionality:**
  * Reads GeoTIFF affine transform matrices.
  * Handles sub-tile cropping when sending large satellite images to PyTorch tensors (e.g. \\(512 \times 512\\) patches), automatically updating offset affine transform matrices to preserve spatial alignment upon re-stitching.

#### **D. Machine Learning Inference Engine (Member 1)**
* **Framework:** PyTorch + `timm` + CUDA.
* **Model Backbone:** `Depth Anything V2` Vision Transformer (ViT).
* **Optimization:** Pre-load weights on server startup. To handle edge-blur at urban structural boundaries, apply adaptive bin classification-regression heads with a Dirichlet Covariance loss formulation.

#### **E. Absolute Scale Calibration Engine (Member 2)**
* **Core Libraries:** `numba`, `scipy`, `scikit-learn`.
* **Pipeline Execution:**
  1. Project co-registered global DEM (e.g., SRTM / COP-DEM) coordinates into camera space.
  2. Run the adapted **Cloth Simulation Filter (CSF)** over the predicted relative point cloud to mask out non-ground structures (buildings, trees).
  3. Execute **RANSAC linear regression** on ground-support points to recover scale (\\(s\\)) and translation shift (\\(t\\)) parameters:
     \\[d_{\text{metric}} = s \cdot D_{\text{rel}} + t\\]
